# Editable Figma, when requested

Use `gpt-6.1-sol` with `high` reasoning for conversion; a smaller model may check exact copy coverage. Model choices follow the host limits and student preference in the main skill.

Figma is optional. Use the student's available Figma tools and their own account; if disconnected, preserve the approved HTML/semantic scenes and explain the connection needed. Never invent a URL or claim live conversion from local exports.

Load available Figma-use guidance before executing Figma JavaScript and create-file guidance before making a file. Inspect the actual page, available fonts and pre-existing nodes. Record a protected baseline and use clear canvas space. Keep a local manifest of source hashes, owned node IDs, frame IDs and source mappings. Names alone are not ownership.

Convert the exact approved scene/HTML batch into one native FRAME per combined spread. Preserve count, dimensions, exact copy, palette, geometry, stacking, crop and font styles. Make native TEXT, editable shapes/vectors, groups and independently replaceable image fills. Starred replacement-image descriptions stay separate editable text. Never substitute whole-spread images or outlined-text SVGs.

`native-scene.json` includes exact strings and existing image data. It is a portable source file, not a Figma document. For custom approved HTML, extract structure from the actual source and rendered geometry; do not guess from a small screenshot. Preserve CSS features that map faithfully to native nodes; disclose unsupported effects.

Respect the connected tool's current limits rather than historical restrictions. Write in useful bounded batches, returning actual IDs and recording each batch locally. Continue successful conversion without repeated full-tree audits or extra sample approvals. If a write fails, inspect the actual resulting state before retrying; never broadly delete/rebuild to recover.

Select actually available fonts. Missing source fonts require a disclosed substitution or an authorized installation/upload; a local font does not prove remote availability. Do not install fonts or modify global plugins silently.

Perform one consolidated structural and visual check: editable text and exact source coverage, count/dimensions, independent image replacement, actual crop fills/masks, clipping, ownership and unchanged protected nodes. Compare real Figma screenshots with the approved source at overview and readable detail. Repair objective errors in owned nodes and recheck affected areas.

Return only verified file/page/frame IDs and URLs. If conversion is partial, identify completed frames and the remaining cause while keeping local deliverables available.
